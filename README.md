## Reglas de Juego / Instrucciones
Bienvenido a Arcane Bastion
¡Tu deber es defender el castillo de Arcane a toda costa!
Deberas enfrentarte a los monstruos que quieren invadir el castillo,para ello deberas usar a los magos elementales.
Hay disponibles dos modos de juego: Facil y Survival
ARROW UP: Mover Arriba
ARROW DOWN : Mover abajo
F: Disparar hechizo
NUM 4 : Terminar partida
